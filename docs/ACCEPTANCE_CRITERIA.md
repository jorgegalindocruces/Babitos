# ACCEPTANCE CRITERIA

-   `npm install` y `npm run build` funcionan.
-   Título y comienzo de partida funcionan.
-   Creator separa ojos y bocas y permite resto de capas.
-   Small/normal/large no cambia hitbox/estadísticas.
-   Random usa solo desbloqueados.
-   Se elige Fuego/Rayo/Roca.
-   Fase 1 permite mover, saltar y atacar.
-   COME es grande y muerde.
-   VUELA es pequeño y puede aparecer en pareja.
-   DA VUELTAS rueda y queda mareado.
-   Enemigos pueden soltar 0-2 monedas.
-   HUD muestra vida, monedas y poder.
-   Boss 1 se llama Babito Corrupto y tiene al menos 3 patrones.
-   Tras Boss 1 se accede a tienda.
-   Empanadilla/Pingüino son aliados.
-   Comprar/equipar cosmético persiste tras recargar.
-   Fases 2/3 existen al menos como placeholders.
